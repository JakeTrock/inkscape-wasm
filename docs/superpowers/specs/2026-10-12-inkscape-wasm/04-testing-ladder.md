# Leg D — Testing Ladder

Goal: intermediary testing so that (a) infeasibility surfaces in hours
not weeks, (b) every leg lands with runnable proof, (c) a failure at any
rung leaves a documented salvage. One rung = one `make check-N` target =
one CI-able script in `tests/`.

## Rungs

| Rung | What | How | Passes when | Kill criterion |
|------|------|-----|-------------|----------------|
| **T0** | Toolchain smoke | `tests/t0/`: C++ program using exceptions, RTTI, std::filesystem-paths, linked with leg-A common flags, run in Node | prints expected output, exit 0 | emsdk broken → fix or upgrade toolchain, nothing else blocked |
| **T1** | Dependency stack | per-package scripts' smoke tests (leg A) + `libgc` decision ladder executed + `pkg-config --modversion` for all 27 packages against sysroot | all stamps present, all tests green in Node | a dependency can't build/patch → port stops at that dep; headless path also affected — document and reassess |
| **T2** | **GTK Broadway in WASM (spike)** | `tests/t2/`: GTK hello world (broadway backend) + byte pipe bridge + patched broadway.js in the harness page; Playwright screenshot | window with label text visible in screenshot, mouse click on button registers | main-loop or bridge unsolvable after both leg-B designs (Asyncify and non-blocking iteration) are tried → **project re-routes to salvage** |
| **T3** | gtkmm in WASM | `tests/t3/`: C++ gtkmm app with a widget, signal handler, cairo draw | signal fires (assert via console log), widget paints | minor — usually solvable; blocking C++ binding issue documented |
| **T4** | lib2geom | its own test suite, emscripten-built, Node | green (subset of suite that avoids platform-specific bits) | geometry lib needs patches — patch in leg A, unlikely fatal |
| **T5** | **Inkscape headless in Node** | `--actions` pipeline: open SVG → export PNG → close; compare against native-build golden | pixelmatch diff within tolerance | engine blockers (GC crash, FS, locale) — each gets a patch attempt; if GC is the blocker, stub GC already decided at T1 |
| **T6** | Inkscape GUI boots | full module in harness page; Playwright waits for broadway canvas | window chrome + toolbox + canvas painted (screenshot, golden) | — |
| **T7** | **v1 acceptance** | scripted Playwright session (leg E harness) | rectangle drawn via tool + canvas click-drag, saved SVG contains `<rect>` with expected geometry, exported PNG golden-matches | — |

**Salvage path (if T2 kills):** T4 + T5 remain valid — the deliverable
becomes a headless WASM Inkscape export engine (SVG→PNG/PDF-ish) with a
web harness. Leg E survives unchanged. Documented in the final report.

## Golden-image testing

- Goldens generated by the **native** Inkscape 1.4.4 build (`make
  native-inkscape`) on this machine, stored in `tests/golden/` (committed
  — they're small PNGs), regenerated only by explicit `make
  goldens-regen` with a recorded reason in the commit message.
- Comparison: `pixelmatch` with per-test thresholds (text rendering
  differs subtly across rasterizers; start at 0.1% pixel diff for
  shape-only files, 2% for text-heavy files; tune once, record in the
  test manifest `tests/manifest.json`).
- Screenshot tests (T2/T3/T6/T7): Playwright headless Chromium, fixed
  viewport 1280×800, `--force-color-profile=srgb`, deviceScaleFactor 1.
  Screenshots committed alongside goldens.

## Test input corpus (`tests/fixtures/`)

Small, purpose-built SVGs — one feature each:

- `basic.svg` — rect, circle, path, stroke, fill (T5 primary)
- `text.svg` — DejaVu text, alignment (font path proof)
- `gradients.svg` — linear + radial
- `transforms.svg` — nested groups, matrix transforms
- `clip-mask.svg` — clipping + masks

## Harness for the rungs

Every rung's test script is standalone (`tests/tN/run.sh` [+ `.mjs` for
Node, `.spec.ts` for Playwright]) so a failing rung can be rerun in
isolation. `make check` = all rungs up to the highest achieved
(`build/stamps/check-N.ok` records progress). Full suites and builds run
under `oc-bg`, per session rules.

## Failure log

`docs/findings.md` — every rung failure gets an entry: symptom, evidence
(log path), diagnosis, fix or kill. This is the research log for the
port, in the spirit of the other RE projects in this repo.
